# Student Information Management System 🎓

A comprehensive desktop application designed to streamline the management of student academic records, attendance, and class schedules. 

## 🚀 Features

* **Complete CRUD Functionality:** Add, read, update, and delete student records in real-time.
* **Instant Reporting:** Automatically generate aggregated reports on class schedules and grade performance.
* **Attendance Tracking:** Monitor and manage student attendance percentages.
* **Seamless Database Integration:** Real-time data persistence using JDBC.

## 🛠️ Tech Stack

* **Language:** Java (JDK)
* **GUI Framework:** Java Swing
* **Database:** MySQL
* **Connectivity:** JDBC (Java Database Connectivity)
* **Build Tool:** Maven
